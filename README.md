# Python шпаргалка

Личная страница-шпаргалка по курсу Stepik «Поколение Python». Два файла:

| Файл | Что это |
|---|---|
| `index.html` | Сама страница. Трогать не нужно. |
| `data.js` | Все сниппеты. **Именно его вы правите**, когда добавляете новое. |

## Публикация на GitHub Pages (один раз, ~5 минут)

1. На GitHub: **New repository** → имя, например `python-cheatsheet` → Public → Create.
2. На странице репозитория: **Add file → Upload files** → перетащите `index.html`, `data.js`, `README.md` → **Commit changes**.
3. **Settings → Pages** (в левом меню) → Source: *Deploy from a branch* → Branch: `main`, папка `/ (root)` → **Save**.
4. Через 1–2 минуты страница доступна по адресу
   `https://<ваш-логин>.github.io/python-cheatsheet/`
   (точный адрес появится вверху той же страницы Settings → Pages).

Добавьте адрес в закладки на телефоне — страница работает везде.

## Как добавлять сниппеты

### Способ 1 — прямо на GitHub (с любого устройства, изменения видны везде)

1. Откройте `data.js` в репозитории → карандаш **Edit** (на телефоне: `⋯` → Edit).
2. Найдите нужный раздел (`// ---------- 7.5 Цикл while ----------`) и допишите блок:

   ```js
   { id: "n1204", section: "7.5 Цикл while", title: "Что делает сниппет",
     code: "num = int(input())\nwhile num > 0:\n    print(num)\n    num -= 1",
     note: "Пояснение или что выводит", tags: ["while", "цифры"], pinned: false },
   ```

   Правила:
   - `id` — любой, лишь бы не повторялся (удобно: `n` + номер раздела + порядковый).
   - В `code` перевод строки — `\n`, кавычка того же типа внутри — `\"`. Четыре пробела отступа пишите как есть.
   - После каждого блока запятая; у самого последнего в списке — нет.
   - Новый раздел: добавьте его название в массив `sections` вверху файла, порядок там = порядок на странице.
3. **Commit changes**. Через минуту страница обновится.

### Способ 2 — на самой странице, потом экспорт

На странице есть **+ Добавить** (или `Ctrl+V` с кодом в буфере), ✎ изменить, ★ закрепить, ✕ удалить. Эти правки хранятся только в браузере этого устройства — над шапкой появится жёлтая плашка со счётчиком.

Чтобы перенести их всем: нажмите **⬇ data.js** — скачается готовый файл со всеми правками → загрузите его в репозиторий (Add file → Upload files, заменит старый) → после этого нажмите **Сбросить правки** на странице.

## Что умеет страница

- Поиск по названию, коду, заметке, тегам и разделу — несколько слов через пробел = все должны встретиться; совпадения подсвечиваются. `/` — фокус в поиск, `Esc` — очистить.
- Теги под карточкой кликабельны — фильтр одним нажатием.
- Чипы разделов сверху, ★ Закреплённые — отдельный фильтр.
- Клик по карточке или ⧉ — код в буфере обмена.
- Разделы сворачиваются (клик по заголовку), «Свернуть все», запоминается.
- «Компактно» — только первые строки кода, без заметок.
- Светлая/тёмная тема (◐), по умолчанию как в системе.
